## Instructions to Capture & Save Screenshots

1. **Launch the local web server:**
   ```powershell
   python -m http.server 8000
   ```
2. **Open the application in your browser:**
   Navigate to `http://localhost:8000`.
3. **Capture each view:**
   - Use the Windows Snipping Tool (`Win + Shift + S`) or browser Developer Tools (`F12` -> `Ctrl + Shift + P` -> `Capture area screenshot`).
   - Capture each of the 6 sections cleanly.
4. **Save in this folder:**
   Save the images directly into `screenshots/` with the exact filenames listed above (`homepage.png`, `about.png`, `skills.png`, `projects.png`, `certifications.png`, `contact.png`).
